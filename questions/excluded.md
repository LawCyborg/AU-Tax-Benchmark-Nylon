# Excluded questions

The source set is the 120 end-of-module review questions, with suggested answers, in *CPA Program Australia Taxation*, 6th edition (2023). The textbook answers apply the law for the 2022–23 income year. The benchmark keeps only questions whose reference answer still holds under the law in force at the run date (October 2026), and grades each answer against that reference, so 29 questions are excluded and 91 remain.

Both screens were applied to the questions and reference answers alone, before any system's answers were scored.
