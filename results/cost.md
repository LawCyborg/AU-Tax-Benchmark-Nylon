# Cost per answer — method

- **Nylon (October Snapshot):** not published. Nylon's cost per answer is commercially sensitive.
- **Comparison systems:** each answer's input and output token counts priced at the provider's published per-token rates, as recorded by the benchmark harness. Web-search charges for these systems are not included (an estimated USD 0.007–0.016 per answer), so their figures are slightly understated.
- Costs are model and search usage only; they exclude hosting and infrastructure.
